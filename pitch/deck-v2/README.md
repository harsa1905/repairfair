# RepairFair pitch deck (version 2)

Open `index.html` in Chrome or Edge. It works offline. Keep this whole folder together.

## Presenting
1. Click once on the deck. This lets the video play with sound.
2. Press **F** for full screen.
3. Press **S** to open the presenter window, with the current and next slides, the script and a timer. Share only the audience window.
4. Use the arrow keys in either window. **O** shows all slides, and **N** shows the notes.

Slide 9 is the demo video. It plays when the slide opens, and the speaker stays silent. If the browser blocks it, click the slide. If you're streaming, remember to share computer audio.

## Before demo day
- Save the finished video as `assets/demo.mp4`. Until then, slide 9 shows a still image.
- Replace the yellow **ADD** tags on slide 17: email and QR code.
- If a person checks the review coding, update the review study backup slide.

## PDF for Canvas
In Chrome or Edge, press Ctrl+P, choose Save as PDF, Landscape, no margins, with background graphics on. Slide 9 prints as a still image, so add the video link in Canvas.
